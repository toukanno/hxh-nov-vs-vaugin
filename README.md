# hxh-nov-vs-vaugin

ハンターハンターのノヴ vs ヴォーギンをモチーフにした、ブラウザで遊べるバトルロワイヤル風アクションゲームです。

## 遊び方

- `W A S D` または `↑←↓→` : 移動
- `Space` : 近距離攻撃（前方扇形）
- `Shift` : 回避ダッシュ（短時間無敵）

## 勝利条件

- ノヴ（プレイヤー）が最後の1人になると勝利
- 体力が0になると敗北

## 起動方法

静的ファイルだけで動作します。例えば以下:

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。
